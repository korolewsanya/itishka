Что я делаю

🌐 Сайты

Разрабатываю сайты любой сложности — от лендингов и корпоративных визиток до полноценных интернет-магазинов с личным кабинетом, корзиной и онлайн-оплатой.

Два подхода в работе

  • На чистом PHP — максимальная лёгкость, прозрачность кода, отсутствие зависимостей.
  • На Laravel — быстрая разработка, масштабируемость, современная экосистема.

Что входит в работу

  • Адаптивный интерфейс и вёрстка
  • Бизнес-логика, работа с БД
  • Кнопки связи через Telegram и WhatsApp
  • Личный кабинет и авторизация
  • REST API для мобильных приложений
  • Деплой: домен, SSL, хостинг
Стек: PHP 8.4, Laravel 13, Livewire 4, Tailwind CSS, Alpine.js, Vite, MySQL, JavaScript, jQuery, AJAX, REST API.

📱 Мобильные приложения

Разрабатываю Android-приложения на Java — как небольшие утилиты для личного использования, так и полноценные бизнес-инструменты, дополняющие веб-проекты.

Что умею

  • Нативные приложения (Java, API 17+)
  • Локальное хранение: SQLite
  • Удалённое хранение: MySQL через REST API
  • Сеть: Volley, JSON, Gson
  • Изображения: Glide
  • Распознавание речи, уведомления, разрешения
  • Полный цикл до публикации в RuStore / Google Play

Два типа проектов

  • Для себя — утилиты: заметки, списки, трекеры
  • Для бизнеса — мобильные админки и CRM-клиенты
Стек: Java, Android SDK, SQLite, Retrofit, Volley, Gson, Glide, REST API, JSON.

⚙️ CRM системы

Разрабатываю CRM-системы и админ-панели для управления бизнесом — от учёта заказов до финансов и сотрудников.

Что входит в CRM

  • Заказы, клиенты, товары, материалы
  • Финансы: доходы, расходы, зарплаты
  • Сотрудники, роли, права доступа
  • Рабочий процесс и этапы производства
  • Отчётность и аналитика
  • REST API для мобильных приложений

Два подхода в работе

  • На чистом PHP — с нуля, включая REST API без фреймворков
  • На Laravel + Filament — современный стек для быстрой разработки
Стек: PHP 8.4, Laravel 13, Livewire 4, Filament 5, MySQL, REST API, Tailwind CSS, Alpine.js, Vite, Java (Android).

Учусь самостоятельно — по документации, исходникам и практике. Не боюсь читать чужой код и разбираться в незнакомых технологиях. За плечами 16 лет работы слесарем на заводе — это научило дисциплине, ответственности и умению доводить дело до конца, даже когда никто не стоит над душой.

Сейчас ищу команду, где смогу расти как инженер и приносить пользу реальными проектами.
